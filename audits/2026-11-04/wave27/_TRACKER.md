# Wave 27 audit 2026-11-04 -- tracker

Three read-only reports by Opus 5.5 low-effort agents on code no earlier wave read: the shared helpers and out-of-fold modules of `feature_engineering/transformer`, the transformers from `active_virtual` to `ks_shift`, and the pair-scoring pipeline of the MRMR filters. The agents could not write files, so the reports are their returned text, condensed; each finding was re-checked on HEAD before it was fixed. Dispositions: RESOLVED (fixed with a test), FUTURE, DOC, REJECTED.

| **DOC** | W27PR-1 | precision | High | the pair operand table is float32, so a pair is scored on float32 operand values while the emitted column is rebuilt in the original dtype; a difference smaller than about 1.2e-7 x max(|a|, |b|) is lost when the operands are stored (epoch-second columns: about 128 s). No code change: the table dtype is a footprint decision made across the numba, GPU and recipe paths, the case needs near-identical operands with a large offset, and no failing fit was reported; a fix would add storage or touch the hot materialise path for a rare input. Subtract a reference point from such columns (for example, time since the start of the period) before the fit. |
