# Wave 2: public API contract audit

Scope: sklearn estimator contracts and mutable defaults under `src/mlframe`. This was a partial pass. The grep for mutable defaults (`def f(x=[]/{}/set())`) found nothing. `__init__` defaults that are mutable objects turned up only `np.float32` / `np.float64` dtype classes, which are immutable and therefore fine. Read in full: `estimators/custom.py` (ArithmAvg, GeomAvg, PureRandom, MyDecorrelator, IdentityEstimator family) and `estimators/early_stopping.py` (`__init__` and parameter validation). About 80 other estimator classes were found by the grep but not read, so this report says nothing about them.
