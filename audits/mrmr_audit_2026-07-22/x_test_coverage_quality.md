# Test Suite Coverage & Quality — Cross-Cutting Audit (2026-07-22)

This cluster does not own a single source file; it audits the **test suite itself** —
`tests/feature_selection/` (1075+ `.py` files across 18 subpackages, plus the historically flat
`test_biz_value_mrmr_layerNN.py` line the task description was written against) — for structural
health: whether the 2026-07-20 audit's 11 test-coverage findings + 16 proposed test files actually
got built; whether this run's 26 new cluster reports' bug fixes are shipping with real regression
tests per the repo's own "every bug fix ships a regression test, same commit" rule; whether the
`layerNN` biz_value family is genuinely independent coverage or copy-pasted padding; and whether
smoke-level `assert x is not None` tests are masquerading as real behavioral contracts. No DB/HTTP/UI
surface exists anywhere in this suite (pure pytest + numpy/pandas/sklearn fixtures) — confirmed by
grep, so finding-angle 9 (SQL/HTTP/UI) is N/A, as expected for computational-library tests.

Revert `self._effective_random_seed()` back to `getattr(self, "random_seed", 0)` locally to confirm the test fails pre-fix, then restore.
2. **(coverage_gap)** For each of the 13 orthogonal-FE modules touched by `f067e0d44` without a dedicated test (hsic, lasso, routing, scorer_auto, three_gate, total_correlation, adaptive_arity, adaptive_degree, bootstrap_mi, cmim, copula_mi, dcor, elasticnet), port the exact slice-replay pattern already proven in `test_jmim.py::TestRecipeFreezesPreprocessParams` (fit on a distributionally-shifted column, assert `preprocess_params` is present and replay matches fit-time values within `rtol=1e-9`). This is mechanical (same fixture shape, different import) and would have caught both `ORTH_SCORING_A-1` and `ORTH_SCORING_B-2` immediately.
3. **(coverage_gap)** Rewrite `test_screen_coverage.py`'s ~20 bare-`is not None` tests to assert the documented behavioral effect of each parameter instead: e.g. `min_relevance_gain=1e9` → assert `len(out.selected) == 0` (or whatever the real return-shape attribute is); `max_runtime_mins=0.0001` → assert the returned diagnostics/candidate-count reflects early termination, not a full sweep; `interactions_max_order=2` → assert at least one pair-level candidate name appears in the output. 4. **(process)** Promote the "core greedy under-selection collapses ~38% of seeds to a single feature" bug (documented only in `test_full_suite_regression.py`'s docstring, X_TEST_COVERAGE_QUALITY-4) to its own tracked finding with an assigned severity and fix owner — it is fully diagnosed (ruled out threshold/fixture causes) and just needs a `fit_impl` triage pass; once fixed, raise the test's `mean_auc` floor back toward 0.85 per the docstring's own stated unblock condition.
