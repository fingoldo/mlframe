## Non-findings / confirmed-clean angles
- `_gpu_policy.gpu_globally_disabled()` — correct: handles `MLFRAME_DISABLE_GPU=1` and `CUDA_VISIBLE_DEVICES=""` (empty), `.strip()`-tolerant. Single source of truth; the bug is callers that don't consult it (GPU_INFRA-2), not this function.
- `_gpu_teardown_guard.install_cuda_teardown_guard` — prior C-2 self-recursion race FIXED: the whole capture+install is now under `_install_lock`; the `sys` pre-bind (`_is_finalizing = sys.is_finalizing`) correctly survives finalization global-clearing. Clean.
- `_fe_gpu_strict` AUTO-fit shape — prior C-1 FIXED: `_AUTO_FIT_N/_P` replaced by `threading.local()` (`_auto_fit_state`); the env flag is read live per call; only the immutable CUDA probe is cached. Clean.
- `_fe_gpu_vram` cushion/pool-cap — the joint bound `pool_cap + cushion <= total` is correct by construction; `_POOL_LIMIT_DONE` set-before-attempt avoids retry storms; permissive-without-cupy is right. The `free_all_blocks()` re-probe before declining is sound. Only the unlocked flag (GPU_INFRA-8) is noted.
- `batch_mi_noise_gate_gpu` dispatcher — prior A-1/A-3 FIXED: `gpu_globally_disabled()` self-check present (line 828), cuda `except Exception` broadened (879). VRAM cushion pre-flight present. Shared-mem-overflow → global-atomic GPU fallback (not CPU) is bit-identical and correctly gated at `_sh_bytes <= budget*0.75` (line 620) with an OOB host screen (535-556). Backend choice via KTC `_batch_mi_noise_gate_backend_choice`, no hardcoded crossover. Clean.
- `batch_pair_mi_gpu` dispatcher — `gpu_globally_disabled()` guard (396), broadened `except Exception` on the cuda path (494), max-joint-cardinality shared-mem overflow routed via `shared_fused_kernel_fits_budget`→row-chunked→CPU (430,502-511), chunk-size via KTC not hardcoded (`_choose_pair_chunk_size`). Clean.
- `batch_pair_usability_corr_gpu` warp kernel — correctness reviewed: all 32 lanes of a warp share `warp_id` so the early-return (line 316) is warp-uniform (no `shfl` mask hazard), full `0xFFFFFFFF` mask valid, two-pass mean-then-center matches `_abs_pearson_form_reduction` including the `cv2` degenerate floor and the `nnan`/`ninf`-excluded fastmath set. Numerically clean; the only issue is the opt-out gap (GPU_INFRA-2).
- `_gpu_hw_launch` occupancy math — analytic max-active-blocks/SM is a correct conservative min over warp/reg/shared/block limits; launch geometry never changes reduction results. Clean apart from the benign unlocked cache.
- `_numba_warmup` / `_prewarm` — no prange-nesting-under-threading deadlock in these files; warmup is a single typed-dict exercise, best-effort, opt-out via env. Clean. (The joblib-over-GPU serial-gating lives in `_pairs_core.py`, outside this cluster.)
- `_fe_cmi_perm_null_gpu` — prior D-12 dead `isinstance(y_h, cp.ndarray)` now documented-in-place (still dead but annotated). No new bug found on a focused read of the dispatch.
- GPU circuit-breaker re-arm (0→1 in-flight-fit transition) — NOT located in any file in this cluster (it lives in `_permutation_null.py`, owned by the screen_confirm / GPU_RESIDENT scope). Not audited here.
- SQL/HTTP/eval/exec/subprocess/pickle-of-untrusted — absent across the whole cluster (grep-confirmed). Angle N/A.
