## Non-findings / confirmed-clean angles
- **`_safe_code_dtype` widening on EVERY discretize call path** — verified present and correct for the QUANTILE path (max real code = `n_bins-1`, NaN→rightmost = `n_bins-1`, both covered) at: `discretize_array:571`, `discretize_2d_quantile_batch:656`, `discretize_2d_array:868`, `discretize_2d_array_cuda:1017`, `discretize_2d_array_cuda_row_chunked:1160`. The ONLY gap is the uniform NaN sentinel (DISCRETIZATION-1).
- **NaN/inf sentinel handling** — CPU/GPU/row-chunked NaN parity for uniform (dedicated NaN code) and quantile (NaN→rightmost via `<`-false binary search, matching numpy `searchsorted` and the RawKernel's `cuts[mid] > v` C semantics) is consistent across backends (DISCRETIZATION-1 GPU-parity fix landed and verified). `_edges_from_quantiles`/`_edges_from_uniform` correctly strip inf via `np.isfinite`.
- **Empty / all-constant / single-value columns** — `discretize_array` empty→`np.empty(0)`; `get_binning_edges` all-NaN→`np.zeros(1)` (the B-1 P0 fix, verified present, avoids the prange-swallowed `np.percentile([])`); `_edges_from_quantiles`/`_edges_from_uniform` return `[]` on `size<=2`/constant; `_knuth_best_M`/`_bayesian_blocks_bin_edges` have degenerate-input guards.
- **Quantile edge computation** uses `np.nanpercentile` consistently on the NaN path; the njit `_quantile_edges_2d_njit` fast path is bit-identical to `np.percentile(axis=0)` only on NaN-free buffers (caller-gated), documented and correct.
- **MDLP y-finiteness mask fold** — verified folded into the SAME mask BEFORE the `int64` cast in all three variants: `mdlp_bin_edges:201`, `mdlp_bin_edges_validated:393`, `mdlp_bin_edges_oos_validated:613`.
- **MDLP permutation-null seeding/determinism** — `_permutation_null_gain_njit` seeds numba RNG per call with `seed + depth*7919 + best_idx` (thread-local numba RNG; deterministic). `mdlp_bin_edges_oos_validated`'s train/holdout split uses `np.random.default_rng(seed)`. Reproducible.
- **CPU/GPU discretize parity** — quantile and uniform branches confirmed selection-equivalent (row-chunked quantile is a documented subsample approximation; uniform is exact).
- **`_fourier_detect_cap.py`** — clean: thread-local cap, env fallback robust to non-numeric values, detection-only (cannot alter cross-thread selection).
- **mypy-cleanliness** — no `param: T = None` implicit-Optionals introduced in the reviewed slice; `Optional[...]` used throughout; `# type: ignore` uses are narrowly justified (`_safe_code_dtype:41`, `apply_bin_edges:560`).
