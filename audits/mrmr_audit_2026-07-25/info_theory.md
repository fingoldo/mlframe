# INFO_THEORY — audit (2026-07-25)

Scope: the mutual-information / entropy / permutation-null / MI-aggregation kernels and dispatchers under
`feature_selection/filters/`: the `info_theory/` subpackage (`_class_encoding`, `_class_mi_kernels`,
`_entropy_kernels`, `_batch_kernels`, `_group_mi`, `_state_and_dispatch`, `_cmi_cuda`, `_cmi_cuda_ktc`,
`__init__`) plus `evaluation.py`, `_evaluation_driver.py`, `permutation.py`, `_permutation_null.py`,
`_conditional_permutation.py`, `_analytic_mi_null.py`, `_mi_aggregator.py`, `_mi_dispatch.py`, `_fastmi.py`,
`_ksg.py`, `_renyi_alpha.py`, `_chao_shen.py`, `_bur_term.py`, `_interaction_information.py`,
`_pid_decomposition.py`, `_relaxmrmr_3d.py`, `_jmim_scorer.py`, `_cmi_perm_stop.py`, `_neural_mi.py`,
`_mah.py`, `fleuret.py`, `_numba_utils.py`. This cluster is the numeric heart of MRMR relevance/redundancy
scoring: the entropy/MI/CMI kernels, their CPU/CUDA twins, the thread-local scoring-mode publish/restore, the
permutation-null hot path, the analytic large-n null, and the standalone estimator zoo. The prior wave
(`mrmr_audit_2026-07-22/info_theory_a.md`, `info_theory_b.md`) landed most fixes; this pass verified those and
looked for new issues against the current source.

## Proposals (perf / refactor / test — not bugs)

1. **VRAM accounting for the XC-resident matrix**: `_should_use_cuda`'s `bytes_needed = p*n*4 + p*joint_size*4` (`_cmi_cuda.py:782`) does not include the whole `factors_data` device copy (`nfeat*n*4`) that `_resident_factors_device` holds resident. It is accounted for indirectly (the `memGetInfo` cushion probe sees it once allocated), so not a bug, but adding the resident-matrix bytes to the explicit estimate would make the pre-launch VRAM gate self-consistent on a shared 4 GB card. Bench: A/B a 100k×500 fit with the XC-resident cache warm vs cold and log `memGetInfo` before/after the first round.
2. **Test the `n_classes_y`/int16 overflow paths** (INFO_THEORY-5/6): no test exercises `n_classes_y` near `MAX_JOINT_CARDINALITY` nor `classes_dtype=int16` at nbins > 32767. Add two targeted regression tests once the guards land.
3. **Carve `evaluation.py`** (INFO_THEORY-1): the `_JMIM_CACHE_STATS` deque + `handle_best_candidate` / `evaluate_gain` scoring helpers are a self-contained block re-exportable from `_evaluation_driver.py`; AST-gate the sibling for unresolved names per CLAUDE.md.
