# FE_FAMILIES_A — audit (2026-07-25)

Cluster scope: the numeric/interaction FE generator families and the engineered-recipe replay package under
`src/mlframe/feature_selection/filters/`. Covers the MI-greedy / CMI-greedy generic constructors
(`_mi_greedy_fe.py`, `_mi_greedy_cmi_fe.py`); the full `engineered_recipes/` package (frozen `EngineeredRecipe`
dataclass, dispatcher, and every per-kind builder/replay submodule); and the numeric/interaction FE families
(`_conditional_gate_fe*.py`, `_conditional_quantile_rank_fe.py`, `_ratio_delta_fe.py`, `_temporal_agg_fe*.py`,
`_numeric_decompose_fe.py`, `_hinge_basis_fe.py`, `_hinge_detect_gpu_resident*.py`, `_periodic_fe.py`,
`_random_fourier_features_fe.py`, `_sliced_inverse_regression_fe.py`, `_ordinal_pattern_fe.py`,
`_integer_lattice_fe*.py`, `_pairwise_modular_fe.py`/`_pairwise_modular_resident.py`, `_extra_basis_fe_proto.py`,
`_fe_additive_fusion*.py`, the gradient/surrogate interaction seeders, and the interaction pre-rank kernels).
This is a mature, heavily-fought corner: nearly every function carries a dated rationale note, and most prior-round
findings that touch this cluster are already fixed (see the "prior findings verified fixed" section). The current-round
yield is two latent-but-real truncation-bug-class findings and one cosmetic sweep; no P0/P1 surfaced.

## Non-findings / confirmed-clean angles

- **Prior-round findings verified FIXED (not re-reported):**
  - MI_GREEDY_RECIPES-1 (hardcoded `0xC011` CMI noise-floor seed): FIXED — `_mi_greedy_cmi_fe.py:1595` now `np.random.SeedSequence([0xC011, seed & 0xFFFFFFFF])`; `seed` is threaded from the constructor's `random_state`.
  - MI_GREEDY_RECIPES-2 (truncating `.astype(int64)` on `y` in the MI/CMI-greedy constructors): FIXED — `_mi_greedy_fe.py:446-453,580-583` and `_mi_greedy_cmi_fe.py:1323-1334,1451-1459` now densify the RAW `y` via `np.unique(return_inverse)` (no pre-cast), with explaining comments. (The residual truncate-cast in the *lattice/modular/additive-fusion* siblings is the NEW FE_FAMILIES_A-1/-2 above.)
  - MI_GREEDY_RECIPES-3 (bare `str(k)` instead of `canonical_group_token` in `_grouped_recipes.py`): FIXED — all five builders (`build_grouped_delta_recipe`, `build_grouped_agg_recipe`, `build_composite_group_agg_recipe`, `build_grouped_quantile_recipe`, `build_target_aware_group_bin_recipe`, lines 31-32,64-66,106-108,144,155-156,178) now call `canonical_group_token(k)`.
  - MI_GREEDY_RECIPES-4 (GPU `greater`/`less`/`equal` dtype divergence): FIXED — `_recipe_unary_binary_gpu.py:172,174,176` now `.astype(cp.int64)` to match the CPU registry, with an explaining comment at 169-171.
- **Leak-safe recipe replay (headline angle): CLEAN across the cluster.** Every `build_*_recipe`/replay path recomputes closed-form from frozen train params with NO `y` reference at transform:
  - Grouped/temporal (`_grouped_recipes.py`): grouped-delta/agg/composite/quantile all store train lookups + global fallbacks; `build_target_aware_group_bin_recipe` stores the supervised MDLP `group_edges` (a frozen fitted binning, refit on train) and explicitly does NOT persist the OOF assignment — replay is `searchsorted` on frozen edges, X-only.
  - Target-encoding-style families store frozen **train** aggregates, which is a legitimate fitted transform, not a leak: `_ordinal_pattern_fe.py:235` (`lookup` = train per-pattern target means + `global_mean`), `_encoding_recipes.py` KFold target encoding (stores frozen means). Replay maps X→stored value; no test-`y` touch.
  - Supervised-projection families store frozen **train**-fitted directions: `_sliced_inverse_regression_fe.py:202` (`x_mean`, `v`); replay is `(x - x_mean) @ v`, X-only — analogous to persisting LDA/PCA coefficients.
  - Pure X-derived: `_conditional_quantile_rank_fe.py:193` (edges + per-bin sorted `x_i` refs), `_numeric_decompose_fe.py:427,446` (rounding/digit extract), `_hinge_basis_fe.py:551` (knots), `_periodic_fe.py:385` (period/op), `_random_fourier_features_fe.py:182` (frozen `W`,`b`,bandwidth), `_integer_lattice_fe.py`/`_pairwise_modular_fe.py` (pure integer arithmetic on X), `_orth_basis_recipes.py` (univariate/pair-cross/diff/cluster/spline/fourier). All leak-free.
- **Seeded-RNG determinism: CLEAN.** No bare `np.random.<fn>` on any hot/parallel path in the cluster — every draw goes through `np.random.default_rng(seed)` / a passed `rng`, seed threaded from `random_state`/`random_seed` (verified in `_conditional_gate_fe*.py`, `_integer_lattice_fe*.py`, `_pairwise_modular_fe.py`, `_ordinal_pattern_fe.py`, `_random_fourier_features_fe.py`, `_gradient_interaction_seeder.py`, `_surrogate_interaction_seeder.py`, `_mi_greedy_cmi_fe.py`).
- **NaN/inf in FE arithmetic: CLEAN on the paths checked.** `_ratio_delta_fe.py` safe-division floors the denominator (`sign_b * max(|b|, eps)`, line 144) and the grouped z-score floors std to 1.0 on zero/NaN (lines 327-328,334,389) then `nan_to_num`s the output (340-341,393). `_integer_lattice_fe.py:180` maps non-finite operands to NaN columns rather than INT64_MIN garbage.
- **CPU/GPU-resident parity (additive fusion): CONSISTENT.** The CPU proposer and `_fe_additive_fusion_gpu_resident.py` share the identical y-densify code (including the FE_FAMILIES_A-1 truncate), so they diverge from correctness together, not from each other; GPU faults fall back to the byte-identical host path.
- **Security (angle 6): N/A.** No `eval`/`exec`/`subprocess`/`os.system`/`pickle.load`/`yaml.load` and no SQL/HTTP/file-path-from-column-name anywhere in the cluster (grep-verified).
