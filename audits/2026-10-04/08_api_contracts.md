# 08 API contracts, estimator protocol, config, back-compat - audit 2026-10-04

Scope: sklearn estimator protocol, pickle back-compat, suite save/load versioning, pydantic configs, public exports, optional-dependency import hygiene. Read-only. Deduplicated against audits/full_audit_2026-09-20/config_contracts.md (CFG-01..32, all CLOSED); nothing below repeats those.

## Method
- Import hygiene: AST scan of module-level (non-try) third-party imports in src/mlframe (excluding _benchmarks, _vendored), compared with pyproject [project.dependencies]; then a blocking import finder (meta_path) simulating a core-only install, importing public entry modules.
- Estimators: enumerated 88 public BaseEstimator subclasses; AST check of __init__ (param assigned non-verbatim), get_params/clone/set_params round trip on the 55 no-arg-constructible ones, AST check of fit bodies for non-underscore attrs, docstring-vs-signature drift; real fit + pickle + transform + refit(6 cols) + set_output probes on RFECV, BorutaShap, ShapProxiedFS, MRMR (tiny data); sklearn estimator_checks on 4 helper estimators; legacy-pickle simulation (delete each fitted attr, call transform) on RFECV/BorutaShap/ShapProxiedFS.
- Configs: 110 pydantic models: extra mode, default construct, model_dump -> re-validate, JSON round trip, shared mutable defaults. Result: 0 failures; 104 forbid, 5 allow (RFECV grouped configs documented intentional at wrappers/rfecv/_configs.py:16,34; CustomParams), 1 ignore (MetricSpec).
- Exports: 717 modules with __all__ checked with getattr on every name: 0 stale, 0 duplicates.
- Suite versioning: read training/core/predict.py:33-100, training/io.py:411-500 and the writers.
