## Checked, no finding

- Every production symbol imported by the 25 scripts exists, and the call signatures match: `_ece_score`, `_ece_score_idx_numba_serial`, `_build_resample_indices`, `_normalize_binary_labels`, `pick_best_calibrator` (keyword-only after `oof_y`), `odds_ratio_combine`, `backtest_override`, `optimize_persistence_floor(_per_class)`, `isotonic_overfit_risk`, `compute_ece_debiased`, and the group, band, sticky and confidence helpers.
- `bench_pick_best_calibrator_index_reuse.py` monkeypatch is effective. `_policy_pick_helpers.py:101` imports `_bootstrap_ece_with_indices` inside the function body, so the attribute on `policy` is read at call time and the legacy stub is seen.
- `bench_compare_postcalibrators_parallel.py` patch target is valid. `post.py:787` calls `get_postcalibrators` through the module global, so the lightweight zoo substitution works.
- `bench_pick_best_calibrator_selection_bias.py:34-38, 57-59`: the held-out set is used only for scoring. No leakage between the selection and the evaluation rows.
- `bench_within_bin_shuffle_iter.py` argsort logic (lines 22-33): stable argsort gives ascending bins and in-bin order matching `np.where`, so the shuffle draws match the legacy path.
- `bench_eci_miller_madow.py:33` Miller-Madow term `(k_obs - 1) / (2N)` and sign convention match production `quality.py:727-729`.
- `bench_ece_debiased_equal_mass.py:80-82` Bernoulli noise-floor term `acc*(1-acc)/(n-1)` matches the debiasing formula, and the empty-bin handling is consistent.
