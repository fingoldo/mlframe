## Checked, no finding

- `_rules.py:172-181` (`minimax_ranking`): the empty-opponents guard is correct. A 1-model leaderboard returns 0.0 and not NaN, so `ranking2top` returns the model.
- `_cw.py:76-80`: the LP inequality direction is right. Each edge requires `sum w*(loser>winner) - sum w*(winner>loser) <= -margin`, which means the winner wins by at least `margin`. The sign convention matches `ranks` (higher score = better).
- `leaderboard_impl.py:152` and `_ensure_majority_graph` diagonal: the diagonal equals 1.0 (0.5 from the tie branch plus 0.5 from `eye`). Condorcet and Copeland read it consistently.
- `_rules.py:122-127` (`baldwin_election`): the loop terminates. Each round removes every model at the minimum Borda score, so the candidate set shrinks, and the loop stops when all remaining scores are equal.
- `leaderboard_impl.py:282`: `reindex` on the sub-ranking keeps `meta_table` row alignment. Ranking functions return Series sorted by score, so the reindex is required and correct.
- `leaderboard_impl.py:165-171`, `:198-204`: the `PARTIAL_METHODS` and `drop_mean` filters use order-preserving lists and not sets, so output column/row order is deterministic.
- `utils.py:11-13` (`ranking2top`): correct for ties. It returns all models at the max. It inherits NaN-max to empty output, which the minimax guard already avoids.
