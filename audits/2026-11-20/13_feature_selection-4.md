## Checked, no finding

- OOF residual alignment (`_shap_proxied_fit_residual.py:285`): `compute_shap_matrix` scatters each fold into original-order accumulators `st.phi`/`st.base` (`_shap_proxy_explain.py`, around lines 740-800), so `residual - residual_pred` is row-aligned.
- Shadow-permutation fast path (`boruta_shap/_shadow_stats.py:162-171`): per-column RNG call order matches the `.apply` fallback, so the stream is unchanged.
- `finite_pool_null_hit_p` (`_shadow_stats.py:72-86`): the linear-interpolation weight matches the order-statistic mixture for a continuous exchangeable draw.
- Row-0 zero initialiser in `history_*` (`__init__.py:780`, `_io_plot.py:36,88`): it only affects row 0, and every reader slices `iloc[1:]`, so no contamination.
- `_fit_with_subsample_stability` size floor (`_fit_explain.py:218`): `min(n, max(10, ...))` avoids `replace=False` oversampling on tiny frames.
- `resolve_su_seeded_pairs` and the other su_seeded screens use isolated RNGs (`_shap_proxied_fit_steps.py:305-310`), so `self._rng` is not advanced.
- `_inject_operand_pairs` (`_shap_proxied_fit_interactions.py:24-46`) computes a real proxy loss for missing pairs rather than stamping the best candidate's loss.
- `_gpu_block_size.block_size_from_tuning_cache` bounds the tuned value to (0, 1024] before use.
