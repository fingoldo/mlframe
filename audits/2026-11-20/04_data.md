## Checked, no finding

- `_rng.py`: name-addressed blake2b streams; entropy includes root seed and segment order, so inserting a column leaves other streams unchanged.
- `_target.py:107-124` `bayes_auc`: tie groups handled correctly (ties count half, self excluded); denominator equals sum over i != j of p_i q_j.
- `_copula.py`: Gaussian/t/Clayton constructions correct (t uses shared chi-square divisor; Clayton is Marshall-Olkin with gamma frailty of shape 1/theta); equicorrelation bound -1/(d-1) correct.
- `_missing.py:80-87`: top-share selection gives the exact requested count; NaN in the ordering ranks lowest as documented.
- `_noise.py:39-71`: uniform and feature-dependent flip updates match p(1-f)+(1-p)f; NoiseSpec refuses an active corruption without an update (spec.py:455-458).
- `_columns.py:78-98`: ar1 lfilter initial state gives the stationary start; `standardize` handles zero variance.
- `_redundant.py:47` and `_economics.py:50`: closed-form residual scales for a target correlation are correct; `_pillars.py:174` proxy weight algebra checked.
- `_oracle_crosscheck.py`: the dit cross-check compares like with like only when each bin holds one level (<= 65 levels), so it does not hide 04-F8; ImportError is raised, not skipped.
- `_scm.py:_check_acyclic` iterative DFS is correct and avoids recursion limits.
