# Cluster 19 "preprocessing" read-only audit

Scope: the 30 files in `audits/2026-11-20/manifests/19_preprocessing.txt`, all under `src/mlframe/preprocessing/_benchmarks/` (worktree at master dd0284ce9). Every listed file was read in full. Callers and definitions in `src/mlframe/preprocessing/*.py` and `src/mlframe/_bench_*_shared.py` were checked by grep and targeted reads, not audited.

No P0 or P1 findings. Every file in scope is a benchmark or profiling harness, so none sits on a default production path. The findings are about whether the benches measure what they claim, plus duplication and nits.

## Checked, no finding

- `bench_update_sub_df_col_copy_elimination.py:30-38`: the OLD reproduction copies `sub_df` before writing `col` (line 33), and `col` is present, so the caller's frame is not mutated across the repeated calls. The identity assert at line 75 is sound.
- `bench_cleaning_cpx18_cpx19.py:36-37`, `:47-50`, `:74-83`: the NaN handling in the masks and the `np.unique` NaN collapse are consistent between OLD and NEW sides, and the identity asserts cover both paths.
- `bench_cb_prep_null_scan_iter120.py:40-64`: the OLD and NEW loops emit the same expressions for every dtype. Gating on dtype membership before `is_null().any()` changes only the work done, not the output, so the "bit-identical" claim holds.
- `bench_count_outofranges99.py:28-39`, `:52-60`: the serial njit reference and the parallel `count_num_outofranges` (`outliers.py:109`) are compared with `np.array_equal` on the same bounds, so the speedup comparison is like for like.
- `bench_outlier_detector_zoo.py:37`: `-decision_function` is the outlier score for IsolationForest, which is the sign convention `select_outlier_threshold` expects.
- Signature check: every public function and keyword that the benches call exists in `src/mlframe/preprocessing/*.py` with the matching parameter name, including the `_get_span_fence_njit` and `_get_count_distinct_njit` re-exports in `cleaning.py:56-88`. No bench is expected to fail at import or call time. This was checked by grep only, not by running them.
- `outliers.py:198,230`: the 20,000-element serial/parallel gate is present as the `bench_nanminmax_serial_gate.py` docstring describes.
