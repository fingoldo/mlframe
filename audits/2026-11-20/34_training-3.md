## Checked, no finding

- `_base_engineering.py` lag, diff, and non-NaN rolling mean and median: each row uses only earlier rows (strictly causal), and the inverse permutation maps back to frame order. The NaN-head behaviour is tested. F1 is the gap.
- `_grouped_causal_bases.py` per-group lag, trailing and expanding kernels: out[j] is set before y[j] is added, and the window buffer evicts the oldest value correctly.
- `_ridge_shared_fold.py`: centring is folded into the right-hand side (X^T(t - t_mean)), and the intercept t_mean - mu@coef is algebraically correct. Imputation uses train-fold means only.
- `_lgb_fold_cache.py` and `_lgb_shared_fold.py`: the subset is built before its label is set, which is the documented fix for the zero-label bug.
- `_eval_stats.py` BH and BY: the BY threshold uses the harmonic number c(m), NaN p-values are kept non-rejectable, and the bootstrap p-value uses add-one smoothing.
- `_interaction_specs.py`: synthetic bases are functions of the parents only, scored on train-sample rows, and div is excluded from base candidates, so no target or held-out row enters a base.
- `_fit_helpers.take_screen_matrix`: the stash is reused only when frame identity, column tuple and row set all match; the permutation is validated with array_equal.
- `_honest_oof_select.cached_honest_prediction`: a cached prediction is reused only when fit rows, eval rows and the valid-mask fingerprint all match.
- `_screening_tiny_perbin._build_yscale_population` and `_yscale_one_fold`: the fallback median and clip bounds use fit rows only, and off-domain validation rows are scored with the train-fold median, as the trained composite predicts.
