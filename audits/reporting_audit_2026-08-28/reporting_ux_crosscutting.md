# Audit report: reporting_ux_crosscutting

**Scope:** all of `src/mlframe/reporting/**` (90 files, ~22k LOC), audited as a consumer-value / UI cross-cutting sweep rather than a per-file line audit (four other clusters cover that).

**Method.** AST-scanned every module in `charts/` for functions constructing a `FigureSpec` (**39 builders across 27 modules**); read `spec.py`, `colors.py`, both renderers, the plotly network and interactivity modules, and the chart-explanation tests in full. Claims verified by building real figures.

**Already-fixed, not re-reported:** px-per-inch parity, top-margin reservation, bar-tick truncation, time-axis formatting, matplotlib-is-save-only, single-panel legend, 2-D PDP support tooltips, the WoE degenerate branch.

## Summary by dimension

1. **Explanatory coverage.** 39 `FigureSpec` builders; **3 set a caption**. 92% of the chart surface ships with a blank how-to-read band, though both renderers already draw it correctly — a pure content gap. Structural sub-problem: six template composers pack a caller-chosen panel mix into one figure, so one figure-level string cannot describe them.
2. **Verdict-on-the-figure.** Two builders compile a verdict into on-figure text. Five more show a traffic-light letter (states the colour, not the consequence). Thirteen compute a decision-grade quantity and drop it.
3. **Degenerate cases.** Annotation panels are used in 19 of 27 chart modules but unevenly WITHIN them. The worst class is not empty axes — it is **fabricated numbers**: the LTR distribution panel prints a mean and a 95% CI of exactly zero on zero queries; the decision curve asserts a confident negative verdict on zero rows.
4. **Title/label hygiene.** Both backends DO wrap suptitles and panel titles, so most reported "clipping" is really **space consumption**: long explanatory prose sits in the suptitle at title font eating three lines of plot area, when the caption band exists for exactly that. One genuine unwrapped path found. Metric direction is almost never stated.
5. **Tooltips.** Only the heatmap has a plotly hover template; scatter, bar, histogram and violin have none. Six of nine panel types have no hover field at all. The network node hover field is supplied by **zero** builders.
6. **Colour.** Measured under simulated deuteranopia/protanopia: the palette's first 10 entries are workable (minimum separation 14.6); the full 20 collapse to **2.8**. The heatmap colormaps are sound. The real problems are colour-as-only-channel and a private duplicate palette.
7. **Parity.** `LinePanelSpec.ylim` is silently ignored by **both** backends despite the decision curve depending on it — verified live.

## Narrative detail

**RUX-1 / RUX-2 — the caption gap.** The spec documents the caption as the how-to-read footnote, and the plumbing is complete: matplotlib wraps at 110 chars, computes a bottom band capped at 30% of figure height and forces constrained layout so the band is reserved; plotly wraps, anchors the annotation at the bottom and grows both bottom margin and figure height per line. Nothing is missing but content. The existing chart-explanation test already states the intent and pins the two exemplars — what is missing is generalising it into an allowlisted sweep. Note the gap cannot be closed by simply writing 36 strings: for the six template composers a fragment mechanism has to exist first, because which panels appear is a runtime decision.

**RUX-4 / RUX-11 — fabricated statistics, the sharpest consumer harm found.** On zero usable queries the LTR distribution panel constructs a single-element fake array, runs its bootstrap over it, and renders a mean and a 95% CI of exactly zero labelled with a count of one. A reader has no way to distinguish that from a genuinely measured zero. The decision curve is the same class in a more surprising place — one of only three charts that does captions right also, on zero rows, prints a confident negative judgement derived from no data. Both reproduced live. The general rule: a builder must never emit a formatted metric string on a path where the underlying n is zero; a text panel naming the mask that emptied the data is the only honest output.

**RUX-40 / RUX-42 — reframing "clipping".** The first hypothesis was that long titles are clipped. Checking the renderers refuted it: both wrap every suptitle line, and panel titles go through a width-scaled wrapper. So the 201-character drift verdict measured on the target-distribution overlay is not clipped — it wraps into three lines of suptitle-size text at the top of the figure, crowding out the plot, while that same figure's caption is empty. The correct finding is placement, not truncation. The one genuine unwrapped path is the confusion-margins panel, which calls the raw title setter while all eight other panel renderers use the wrapping helper, and is the only panel type carrying a note field.

**RUX-54 / RUX-55 — measured, not asserted.** Rather than repeat the usual claim, deuteranopia and protanopia were simulated over the palette. Under that model the base palette's green/red pair separates by 43.1 and 26.9 — uncomfortable but not a collision — and the minimum across all base pairs is 14.6. The genuine failure is the extension: ten pairs below 12, the worst at 2.8, all lightness-only variants. Separately, the multiclass module does not use the shared palette at all; it defines a private interleaved one in which class 0 and class 1 are the dark and light versions of the same blue. That both violates the single-source-of-truth docstring and puts the weakest colour distinction at the MOST COMMON class count. One alternative reading is flagged: a linear CVD matrix is an approximation, so a 14.6 separation is an upper bound on safety — the robust fix (auto-cycled line styles) is cheap and removes the need to adjudicate the simulation.

**RUX-62 — a spec field both backends ignore.** The field's docstring explains its purpose exactly: clipping a net-benefit panel's floor below a steeply-diving reference so the informative region stays readable. The decision curve computes it and passes it. Rendering that spec, matplotlib returned a pure-autoscale range and plotly returned none — the field is read only inside the scatter path on both backends. So one of the three charts held up as the quality bar shipped with the readability fix its own author wrote silently disabled. This is the finding that most argues for the parity meta-test shape: sweep every spec field, render with a non-default value, and assert the output actually changes on both backends.
