## Summary by dimension

1. **Correctness (statistical):** the largest yield, and severe. Three P1s, all confirmed by running the shipped code. (a) `binary.py`'s PIT panel uses a PIT definition provably non-uniform for a perfectly calibrated binary model — a calibrated model produces a linearly-rising histogram (measured densities 0.10 to 1.90 across ten bins) and KS-vs-uniform 0.247, so the panel's stated verdict ("uniform = perfect calibration") inverts on real data. (b) `calibration_heatmap_2d.py` labels a mean gap as "ECE" everywhere; over- and under-confidence cancel within a cell, and a synthetic maximally-miscalibrated cell reports a worst-cell value of 0.000 and a green traffic light. (c) the same module's fixed 0.05/0.10 thresholds are a pure sample-size readout: a perfectly calibrated model reads red at 40 rows/cell, amber at 200, green at 4,000. Alongside: `calibration_by_feature.py` uses the plug-in ECE, the exact bias `calibration_drift.py` documents having fixed. Lower-severity: KS evaluated mid-tie-block, an AP bootstrap CI paired with a full-n point estimate, a NaN bar width.
2. **Computational efficiency:** the PR panel's AP bootstrap CI costs 3.01s vs 0.046s without it at n=500k (65x, dominating the figure) and allocates a 200 MB index block. Also: an object-column hashability probe iterating every row in Python (0.54s per 1M-row column), a discarded count pass, and per-bin full-array masks despite an O(n) docstring claim.
3. **Architecture and clarity:** `binary.py` at 827 LOC is inside the carve band. Dead private aliases, a docstring promising a band the code never builds, annotations violated by None padding.
4. **Informativeness / DS value:** `FigureSpec.caption` is populated by exactly 3 modules repo-wide; five builders in this scope ship no caption. `SCORE_DIST` hides class imbalance via per-class density; the THRESHOLD panel marks no optimum and can decimate it away; drift windows are labelled w0..w9 with no date or count.
5. **UI/UX:** mixed linestyle vocabularies in one tuple, three-line panel titles where a caption belongs, a ragged grid bypassing the layout helper, labels emitted at NaN coordinates.
6. **Edge cases:** generally strong — nearly every builder returns an explanatory annotation panel on degenerate input. Gaps: NaN bar width, silent label-value dropping, ACF gap-closing.
7. **Test coverage:** structural coverage is good (57 tests in the binary chart file alone), but every P1 is outside what the tests assert. All three are cheap "calibrated-model-must-read-green" meta-tests.
8. **OSS hygiene:** clean. Two nits: one refactor-history clause and dash-in-prose in user-visible strings.

## Narrative detail

All quantitative statements below were produced by running the shipped code in-process against `src/`.

**-1 (PIT non-uniform under calibration).** With a uniform-probability calibrated model, the ten-bin PIT density came back as the exact linear ramp `[0.10, 0.30, 0.51, 0.71, 0.91, 1.10, 1.29, 1.49, 1.68, 1.90]` with KS 0.247; a calibrated constant-probability model gives two spikes and KS 0.400. The derivation: with `p ~ U(0,1)` and `y ~ Bernoulli(p)`, both branches contribute `u` at `u`, totalling `2u` — triangular, not flat. The randomised PIT (drawing uniformly on the predictive CDF's jump interval at `y`) is the construction that IS uniform under calibration. The existing test asserts only panel type and title format, which is why this survived.

**-2 / -3 (heatmap metric and verdict).** For -2, a cell holding half `score=0.9, y=0` and half `score=0.1, y=1` has equal means, so the shipped function returned a worst-cell value of 0.0 and a green light. The module docstring does say "calibration GAP", so the intent was known — but the dict key, the headline, the colorbar label and the thresholds all assert ECE, a stronger property. For -3, a perfectly calibrated model with pure-noise features gave worst-cell 0.157 (red) at ~40 rows/cell, 0.082 (amber) at ~200, 0.015 (green) at ~4,000 — tracking the reciprocal square root of the cell count. The two compound: -2 makes the metric miss real miscalibration, -3 makes it invent fake miscalibration.

**-4 (plug-in ECE bias).** The sibling `calibration_drift.py:169-172` carries an explicit note that the plug-in ECE on small windows is inflated and was producing a spurious trend that was purely a sample-size artifact. `calibration_by_feature` still routes through the biased estimator: a calibrated model at n=200 gave per-bin `[0.145, 0.158, 0.124, 0.073]`, heterogeneity 0.085, amber; at n=200k, 0.003. The per-bin dict is returned to the suite's metrics, so the inflated values propagate beyond the figure. The debiased estimator already exists in the same package — a one-line swap.

**-5 (AP CI dominates the figure).** Timed at n=500k warm: `ap_ci=True` 3.011s, `ap_ci=False` 0.046s, ROC panel 0.044s. The module docstring claims a single shared sort and a ~0.96s build at n=2M; the CI path re-sorts full n and sorts the subsample again, so one default-on annotation costs 65x the panel it annotates.

**-9 (per-row Python scan).** The unhashable-column guard short-circuits on the first non-scalar, so an embedding column is cheap — but a plain string object column, the common case, scans all n rows in the interpreter. Measured on a 2-column, 1M-row object frame: 1.25s total, of which one column's scan alone was 0.54s.
