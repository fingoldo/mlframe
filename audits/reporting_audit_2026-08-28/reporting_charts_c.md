## Summary by dimension

1. **Correctness (statistical):** largest yield. Two P1s: the fan chart fills and labels the INNERMOST quantile band while its docstring promises the outermost envelope (confirmed live); and `shap_per_instance` ranks NaN-severity rows as the "worst" errors (a reversed argsort puts NaN first — confirmed live), so it explains rows with no label and then raises on the integer cast. Beyond those: the prediction-stability agreement statistic is tautologically 0.5 (measured exactly 0.5000 at M=3 and M=10); the split-comparison overfit light uses FIXED thresholds with no sample-size scaling and never shows per-split n; the slice finder maximises over thousands of candidates with no per-slice SE or multiple-comparison correction; several degenerate branches return a reassuring number instead of an explanation.
2. **Computational efficiency:** kernels are already well optimised. Real waste in three places: `shap_per_instance` SHAP-explains up to 2000 background rows to use about four (~500x waste) and builds its background index with an O(n) Python comprehension; the spectral "sparse" path materialises the dense Laplacian before converting; a SHAP score proxy runs a full-n predict purely to rank rows for an 8k subsample.
3. **Architecture:** two independent Spearman implementations with DIFFERENT tie conventions, plus a third njit path. `pdp_ice.py` at 785 LOC is inside the carve band. One dead import with a false justification comment.
4. **Informativeness / DS value:** weakest dimension. `risk_coverage.py` is the only builder in scope with a caption, and it is exemplary. Ten other spec builders ship without one; several state no verdict at all (training curves never compute the train/val divergence their docstring says the panel exists to expose; temporal bins carry no support or CI).
5. **UI/UX:** the reported "Reliability curve per window" clipping did NOT reproduce on current code in either backend (measurements below); one structural gap found and reported instead. Also: an unbounded figsize in feature count (500 features gives a 252-inch square), up to 50 categorical ACF ticks, and a column-padded text table in a proportional font.
6. **Edge cases:** several confirmed live — a missing train split makes every normalised bar exactly 0.0; all-NaN quantile predictions produce a clean bill of health; NaN severity in the SHAP panel; a centring flag that labels without centring.
7. **Test coverage:** every scope file has a test file (3,611 test LOC), but the degenerate paths above are untested — searching the three most affected test files for NaN returns nothing.
8. **OSS hygiene:** 8 process/finding-ID markers, one refactor-history date stamp, and the only two non-ASCII lines in the cluster where every sibling uses ASCII.

## Narrative detail

**-1 (fan chart fills the wrong band).** The symmetric-pair helper walks outward-in, so its list is OUTERMOST FIRST. The panel takes all but the last element for the dotted edges and the LAST for the filled band. For five alphas that makes the filled band the inner pair and the dotted lines the outer pair — the inverse of the docstring two lines above. Confirmed by running the builder on a 0.05..0.95 grid: the helper returned the outer pair first and the panel's band label was the 50% pair. The depth shading inherits the inversion. A reader takes the shaded envelope for the 90% predictive interval and gets the 50% one — roughly a 2x understatement of forecast uncertainty.

**-2 (NaN rows ranked as worst errors).** Severity propagates NaN; argsort places NaN at the END ascending and the code reverses it, so NaN comes first. Verified directly. Those rows are SHAP-explained and rendered; the binary title then casts NaN to int and raises. So any NaN in the labels or scores either crashes the panel or silently spends every explanation slot on uninformative rows. The author was already NaN-aware two lines below, which makes the unguarded argsort an oversight rather than a design choice.

**-4 (agreement is 0.5 by construction).** The threshold defaults to the median of the spread on the only path the composer uses, then agreement is the fraction at or below it. The fraction of a sample below its own median is 0.5 up to ties. Measured exactly 0.5000 for 3-member and 10-member ensembles at n=5000, while the suptitle prints it as a measured property.

**-5 / -6 / -7 (degenerate branches returning a passing grade).** All three confirmed by running the code. A NaN train AUC renders a GREEN light with an N/A label — the colour is what the eye reads first. An all-NaN quantile matrix returns a confident all-clear from zero rows, in a panel whose docstring says any non-zero bar is a correctness problem, so zero reads as clean. A regression figure with no train split returned three of four bars flat-zero; the same call WITH a train split returned real values, confirming the mechanism.

**-8 (slice finder winner's curse).** The search evaluates thousands to tens of thousands of candidate cells and reports the maximum. At the default support floor a qualifying slice at n=1000 has 10 rows, whose mean error has a large SE; the max of thousands of such means is strongly upward-biased even with no real weak region. Display order is by raw mean error, not the support-weighted score the docstring spends a paragraph justifying — so the top bar and the field consumers read are systematically the smallest, noisiest qualifying slice.

**Reported "Reliability curve per window" clipping — NOT REPRODUCED; here is what was measured.** Rendered through both renderers on synthetic drift data (n=20,000), with numeric and with real timestamps. matplotlib: figure 900 px tall; the row-0 title occupies a band with 4.2 px headroom and the reliability title sits comfortably inside the row gap; saving through the renderer and scanning the PNG for ink gives a first inked row of 15 of 921, so nothing touches the top edge. plotly: the row-0 title annotation sits inside the top margin band and the reliability title at the top of the second domain, inside the vertical gap. A deliberately over-long panel title on a single-panel, no-suptitle spec also did not clip, because the title wraps to a width-scaled budget first. Alternative readings that could not be ruled out: a different matplotlib/plotly version whose constrained-layout accounting differs; a caller composing the panel into a spec WITHOUT constrained layout (the single-panel branch of the drift builder does exactly that); or an HTML embedding constraining the figure box. The one structural defect that can be evidenced is -40. Recommendation: fix -40, set constrained layout on the single-panel branch too, and add the bbox-containment meta-test so the defect is caught mechanically rather than by eye.

**Proposed captions (-23).** `risk_coverage.py` is the model. Proposed text exists for all ten missing builders (PDP/ICE, prediction stability, quantile, regression, slice finder, spectral embedding, split comparison, temporal audit, target ACF, training curve); see the cross-cutting report's inventory, which carries the same text in a single consolidated table.
